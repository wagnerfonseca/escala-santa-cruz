# Escala Santa Cruz — mockup v2

Site estático (HTML/CSS/JS) com visual minimalista (branco + um accent lilás, Inter).

## Como ver

```bash
cd /workspace/escala-site-v2
python3 -m http.server 8765
# abrir http://127.0.0.1:8765/
```

Dados em `dados.json` (convertidos de `wa-export-novo/dados-historicos.json`; a fonte não é alterada).

## Seções

1. Header + seletor de ano + busca
2. Próximo culto + mês atual
3. Painel do ano (totais, top músicas/músicos/artistas)
4. Lista expansível de meses

Não publicado em lugar nenhum.
